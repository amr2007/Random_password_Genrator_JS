🔐 Password Generator (HTML, CSS, JavaScript)

A simple password generator with a clean UI and a built-in strength meter.

✨ Features

Choose custom password length

Toggle lowercase, uppercase, numbers, and symbols

Generates a fully random password using a dynamic character pool

Strength meter that checks:

password length

character variety (lower/upper/number/symbol)

Animated strength bar (Weak / Medium / Strong)

Minimal and responsive design
